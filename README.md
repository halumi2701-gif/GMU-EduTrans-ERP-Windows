# GMU EduTrans ERP — Windows

Native Windows desktop client for GMU EduTrans ERP.

- UI: WinUI 3 / Windows App SDK
- Runtime: .NET 8
- Architecture: MVVM-oriented desktop modules
- Distribution: Windows x64 Setup.exe
- Production ERP remains independent from this repository.

## Modules
Dashboard, Booking, Sales CRM, Program, Operations, Finance, HR/Payroll, Reports, Notifications, Settings.
